# 🧩 Calculate Samantha's and Lisa's Total Sales Revenue

## Description
Calculate the combined total sales revenue generated by the salespersons 'Samantha' and 'Lisa'.

## Table Schema

| Column Name | Data Type |
| :--- | :--- |
| `id` | bigint |
| `sales_revenue` | bigint |
| `salesperson` | text |
| `widget_sales` | bigint |

## Goal
Return a single column containing the total sales revenue generated by Samantha and Lisa combined.

## Approach

* **Main idea:** Filter the records specifically for 'Samantha' and 'Lisa' and aggregate their total revenue.
* **SQL concept used:** `SUM()` aggregate function and `WHERE` filtering clause with logical operators.
* **Key step:** Filter rows where `salesperson` matches either 'Samantha' or 'Lisa', then sum the `sales_revenue` column.

## SQL

```sql
SELECT 
    SUM(sales_revenue) AS total_revenue
FROM sales_performance
WHERE salesperson = 'Samantha' OR salesperson = 'Lisa';
